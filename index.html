01 시작 전 준비물

아바타 추가에 필요한 자료 4가지

모두 외부 서비스에서 발급·설정하는 값이라 시간이 걸릴 수 있습니다. 설치보다 먼저 준비해 두면 계좌 등록이 한 번에 끝납니다. 각 카드가 만들어 내는 값이 곧 설정 마법사에 입력할 항목입니다.

01
Google Sheets

구글 시트 사본 만들기

아바타는 매매 대상·수량을 시트에서 읽고 상태를 기록합니다. 배포본 “아바타 V3.8”을 내 계정으로 복사해 씁니다.

  • 아래 …/copy 링크 접속 → 사본 만들기
  • 열린 사본의 주소창 URL 전체 복사
  • 원본 URL이 아닌 내 사본 URL이어야 함
https://docs.google.com/spreadsheets/d/1Fu4cXOxdI_QGbNN-3sbXpk5SzvpvfLxuRbfYIhWDCsY/copy
→ 마법사 시트 URL
02
Google Cloud Console

서비스계정 JSON + 시트 공유

사람 대신 서비스계정(로봇 계정)이 시트에 접근합니다. JSON 키를 받고, 그 계정을 시트에 공유해야 합니다.

  • Sheets API 사용 설정
  • 서비스계정 생성 → 키 추가 → JSON 다운로드
  • JSON의 client_email 을 시트에 편집자로 공유
  • 공유 누락 시 시트 접근 오류
→ 마법사 서비스계정 JSON(파일)
03
openapi.kiwoom.com

키움 앱키·시크릿키 + IP 등록

주문·조회·시세를 키움 REST API로 처리합니다. 키를 발급받고 실행할 PC의 IP를 등록합니다.

  • 계좌 등록이 먼저 — 그래야 키 발급 화면으로 진행
  • 앱키·시크릿키 발급 (다운로드 1회)
  • 실행 PC 공인 IP 등록(최대 10개)
  • 미등록 IP 호출은 거부됨
→ 마법사 앱키 · 시크릿키
04
Telegram

텔레그램 봇 토큰 + chat_id

실행·체결 알림과 원격 명령에 씁니다. 봇을 만들고 내 대화 id를 확인합니다.

  • @BotFather → /newbot → 봇 토큰
  • chat_id: 봇에 메시지 후 getUpdates
  • 또는 @userinfobot 으로 내 id 확인
→ 마법사 봇 토큰 · chat_id
🔒
앱키·시크릿키·서비스계정 JSON·봇 토큰 은 실제 계좌와 시트의 열쇠입니다. 타인과 공유하거나 공개된 곳에 올리지 마세요.
02 시트 설정

사본을 만든 뒤, 딱 두 곳만 채웁니다

준비물 1‑1에서 만든 내 시트 사본을 열어 ITEM 시트(전체 자금·거래 개수)와 종목 탭(종목별 설정)을 채웁니다. 노란 칸이 입력 칸이지만, 실제로 손대야 할 곳은 아래 번호로 표시한 칸뿐입니다 — 회차표·수익률·금액 등 나머지는 전부 자동 계산됩니다.

ITEM 시트 — 전체 설정

그리고 시트를 아래로 스크롤하면 나오는 성과 집계 구역에 ④ 시작날짜가 있습니다.

표시칸무엇인가넣을 값
1작업개수작업표에서 위에서부터 이 개수만큼만 거래합니다운용할 종목 수 (예: 2 → 위 2개 종목만)
2투입원금이 계좌에 실제로 투입한 원금투입 금액 (예: $20,000)
3배정비율각 종목에 배분할 비중 (작업표 종목별)원하는 비율(%) — 종목별로 조정
4시작날짜성과 집계를 시작할 날짜 (A39)운용 시작일 (예: 2026-07-27)
💡
나머지는 건드리지 마세요. 계좌번호·배정금액·수익률 등은 자동이고, 종목 티커는 종목 탭에서 자동으로 가져옵니다. ‘작동/멈춤’ 칸은 아바타 실행 상태 표시일 뿐입니다.
종목 탭 Dragon · Tiger · Lamb — 종목별 설정

운용할 종목 수만큼 탭을 씁니다(예: 2종목이면 Dragon·Tiger). 각 탭에서 아래 4칸만 설정합니다.

표시칸무엇인가넣을 값
1Symbol이 탭에서 거래할 종목 티커원하는 종목 (예: SOXL)
2Start Date 시작날짜매매 시작일 — 히스토리 기록에 사용반드시 입력 (예: 2025-01-01)
3Tier 분할분할 회차 수수정 가능하나 40 권장(그대로 두기)
4첫매수가첫 매수 기준 가격현재 주가를 입력
⚠️
회차표(5행 아래의 사다리)는 사용하지 않습니다 — 자동 표시용이니 건드리지 마세요. 종목을 바꾸려면 그 탭의 Symbol만 바꾸면 ITEM에 자동 반영됩니다.
03 다운로드 & 설치

받아서 실행하면 트레이에 상주합니다

이 프로그램은 설치가 필요 없는 단일 실행 파일(포터블 exe)입니다. 창이 없는 트레이 앱이라, 모든 조작은 트레이 아이콘 우클릭 메뉴에서 합니다.

  1. 릴리즈 페이지에서 최신 Avatar.exe 를 내려받습니다. 최상단 최신 릴리즈의 첨부 파일을 받으세요.
    https://github.com/gbsmfather/avatar-releases/releases
  2. 받은 Avatar.exe 를 원하는 폴더(예: C:\Avatar\)에 두고 더블클릭해 실행합니다.
  3. “Windows의 PC 보호”(SmartScreen) 경고가 뜨면 추가 정보 → 실행 을 누릅니다.
  4. 작업표시줄 시계 옆 트레이에 아바타 아이콘이 나타납니다. 안 보이면 ^(숨겨진 아이콘 표시)를 확인하세요.
🔄
업데이트는 자동입니다. 트레이는 매일 프리장 시작 때 새 버전을 확인해 스스로 업데이트하고, 실행 중이던 계좌는 업데이트 후 자동으로 다시 시작됩니다. 지금 바로 확인하려면 트레이 우클릭 → “업데이트 확인” 을 누르세요.
04 아바타 추가 · 설정 마법사

준비한 값을 넣어 계좌를 등록

트레이 우클릭 → “아바타 추가…” 를 누르면 내 컴퓨터 안에서만 열리는 설정 페이지가 뜹니다. 아래 값을 입력하세요 — 키·토큰은 붙여넣기 확인을 위해 평문으로 표시됩니다.

구역항목입력값출처
아바타이름트레이에 표시될 계좌 이름 (예: 국내주식)자유
키움앱키키움 App Key준비물 03
키움시크릿키키움 Secret Key준비물 03

  1. 입력 확인 을 눌러 값 검사 — 오류가 있으면 어떤 항목인지 표시됩니다.
  2. 이상 없으면 저장 — 설정 페이지가 자동으로 닫히고 트레이 “아바타” 목록에 추가됩니다.

여러 계좌를 운용하려면 “아바타 추가…” 를 반복해 계좌별로 등록하면 됩니다.
05 아바타 실행

계좌를 클릭하면 매매가 시작됩니다

  1. 트레이 우클릭 → “아바타” 에 마우스를 올리면 등록된 계좌 목록이 나옵니다.
  2. 실행할 계좌 이름을 클릭 — 시작되면 메뉴에 체크 표시가 붙습니다.
  3. 정상 기동되면 텔레그램으로 시작 알림이 옵니다 — 먼저 “🚶 Avatar 출근하는 중…”(기동 시작), 시트 준비가 끝나면 “Avatar 출근했습니다”(매매 준비 완료) 순서로 두 번 옵니다.
  4. 장중이면 시트 설정대로 매매, 장 마감이면 접속만 하고 정산 후 대기합니다.
📈
실행 상태·체결 이벤트는 텔레그램으로 통지되고 구글 시트에도 기록됩니다. 프로그램 창을 계속 열어둘 필요가 없습니다.
상태 상태 한눈에 보기 — 트레이 아이콘에 마우스 올리기

트레이 아이콘 위에 마우스를 올리면 계좌별 현재 상태가 한 줄로 나옵니다 (예: Avatar — 국내주식 ● 장중(남 213분)·미체결 3·시트 40초 전 / 해외 ✓ 퇴근). 아이콘 색은 셋뿐입니다 — 초록 정상, 노랑 이상(아래 ! 항목이 하나라도 있음), 회색 전부 중지.

표시뜻
○ 중지실행하지 않음
○ 재시작 대기업데이트·이름 변경 뒤 자동으로 다시 시작될 차례
◐ 외부 실행트레이 관리 밖에서 돌고 있음(트레이가 비정상 종료됐다가 다시 뜬 경우) — 트레이에서 중지·시작할 수 없으니 확인 필요
◔ 기동 중 / ◔ 시트 로딩시작 직후 — 키움·시트 연결 중
◑ 장외 대기 / ◑ 휴장 대기장이 닫혀 있어 다음 장까지 대기
● 프리장 / ● 장중(남 N분) / ● 애프터 / ● 주간장매매 사이클 진행 중. ·미체결 n은 걸어둔 주문 수, ·시트 N초 전은 시트를 마지막으로 읽은 시각
◆ 퇴근 중 / ◆ 랩업 중(n회차)마감 절차 — 미체결 취소 / 당일 정산 기록
✓ 퇴근오늘 정산까지 끝남, 다음 장 대기
‖ 일시정지텔레그램 /pause 또는 트레이 메뉴로 일시정지 상태 — 매매하지 않음
◌ 정지 중중지 명령을 받아 미체결을 취소하고 정리하는 중
! 시트 N분 지연 / ! 시트 갱신 없음시트를 15분 넘게 못 읽음 — 인터넷·구글 시트 확인
! 키움 조회 N분 지연매매 중인데 키움 조회가 15분 넘게 없음 — 아바타가 멈췄을 수 있으니 재시작 고려
! 사이클 오류직전 매매 사이클에서 오류 — 텔레그램 알림과 로그 확인
자동 자동 시작 — 트레이가 뜰 때 계좌를 자동 실행

매번 계좌를 손으로 클릭하지 않아도 됩니다. 자동 시작으로 표시해 두면 트레이를 실행할 때 그 계좌가 함께 시작됩니다 — PC 재부팅 후에도 트레이만 실행하면 매매가 이어집니다.

  1. 트레이 우클릭 → “자동 시작” 에 마우스를 올리면 계좌 목록이 나옵니다.
  2. 자동 시작할 계좌를 클릭해 체크합니다(다시 클릭하면 해제).
  3. 설정은 다음 트레이 실행부터 적용됩니다 — 트레이가 뜨면 체크된 계좌가 자동 실행되고 풍선 알림으로 알려줍니다.
이름 이름 변경 — 계좌 표시 이름 바꾸기

추가할 때 정한 이름은 나중에 바꿀 수 있습니다. 프로필 폴더도 새 이름으로 함께 바뀌며, 설정·데이터·자동 시작 여부는 그대로 유지됩니다.

  1. 바꿀 계좌를 먼저 중지합니다(실행 중인 계좌는 목록에 나오지 않습니다).
  2. 트레이 우클릭 → “이름 변경” 에 마우스를 올려 계좌를 클릭합니다.
  3. 브라우저에 작은 입력 창이 열립니다 — 새 이름을 입력하고 저장하면 끝입니다.
확인 텔레그램으로 실행 확인

아바타가 잘 돌고 있는지 텔레그램 명령어로 바로 확인할 수 있습니다. 준비물 1‑4에서 등록한 내 대화(chat_id)에서 명령을 보내면 봇이 답합니다 — 먼저 /status 를 보내보세요.

06 아바타 종료

계좌 중지 → 앱 종료, 두 단계

앱은 실행 중인 계좌가 하나라도 있으면 종료되지 않도록 막혀 있습니다 — 주문을 남긴 채 꺼지는 것을 방지합니다.

6-1 계좌 중지 — 미체결 자동 취소 포함
  1. 트레이 우클릭 → “아바타” → 실행 중(체크된) 계좌 클릭.
  2. 확인창에서 예 를 누르면 중지가 시작됩니다.
    Avatar 계좌 중지 확인계좌 아바타 ‘○○’ 를 중지합니다. 미체결 주문이 있으면 모두 취소한 뒤 중지합니다. 중지하시겠습니까?
  3. 진행 창이 아바타의 현재 단계(미체결 취소 중…, 랩업 중 등)를 실시간 표시하고, 정리가 끝나면 자동으로 닫힙니다.
6-2 트레이 종료
  1. 모든 계좌를 중지하면 트레이 “종료” 가 활성화됩니다. 실행 중이면 “종료 (실행 중 계좌 중지 필요)” 로 비활성입니다.
  2. “종료” 클릭 → 확인창에서 예 → 트레이 앱이 종료되고 아이콘이 사라집니다.
    Avatar 종료 확인Avatar 트레이를 종료합니다. 종료하시겠습니까?
⚠️
강제 종료·전원 차단 등 정상 절차가 아닌 종료에서는 미체결 자동 취소가 동작하지 않을 수 있습니다. 종료는 반드시 위 절차를 따르세요.
🗑️
더 이상 쓰지 않는 계좌는 중지한 뒤 트레이 우클릭 → “아바타 삭제…” 에서 지울 수 있습니다(확인창이 뜹니다). 실행 중인 계좌는 삭제 목록에 나타나지 않습니다.
